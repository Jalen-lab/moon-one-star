# The Moon Gets One Star

One line, a one-star review of the Moon:

> ★☆☆☆☆ Runs the tides, the calendar and my sleep, takes a week off every month, and has never answered one email.

The judge's brief weighs five things, most important first: the line
is a one-star review of the Moon itself; it is the funnier of the two,
the bigger and quicker laugh winning on first read; it reads like a
real review, with a rating or a grievance a genuine reviewer would
leave; it finds a specific, surprising grievance about the Moon instead
of the obvious jokes about craters, cheese or how bright it is; and it
uses its few characters well, the punchline landing before the limit.

The stars up front make it read as a real review before a single word
is read. Then the grievance is a job description no other object in
the sky could hold: the Moon runs the tides, the calendar and the
reviewer's sleep, it takes a week off every month when it goes dark,
and after all that it has never answered one email. The joke is
specific to the Moon twice over — the tides and the monthly
disappearance — and nothing in it could be swapped for another product.

## How to run

```sh
python3 main.py
```

The program writes exactly that line, and nothing else, to
`entry.txt` in `$MAKEFUN_OUTPUT_DIR` (default `/output`) — 112
characters, inside the 1–120 character gate, a single line. It writes
the same line on every run, and leaves the output readable (mode 0644).
